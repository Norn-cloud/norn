# norn-kernel

`norn-kernel` is a ring 0 crate (pure, portable semantic core): sans-IO decider + CellHost trait/effects. Its dependency boundary is in `boundary.json` and enforced by `norn-skeleton-guard`. It holds the pure Decider form (T2-KER-1, #2533): the `Decider` trait, the closed serializable `Effect` ADT (perform / schedule / cancel timer), host-supplied `Observations` (logical time, entropy, world), and the tick-shaped `step`. The host-facing four-verb `CellHost` trait (T4-CELL-1, `cell_host`) replaces `DurableContext`: `commit` applies fact writes, appends ledger events, enqueues commands and timers, and consumes the triggering delivery in one transaction; `perform`, `observe`, and `clock` deliver results, observations, and due timers back as kernel inputs; `serialize_by` and `publish` are the ordering and reactive-push hooks. The in-memory reference host and the host-agnostic `CellHost` laws live in `norn-testkit` (`cell_host`), so every host driver runs the same laws.
