# What's proved, what's not

Run `bash scripts/demo/drop-12-guarantees.sh` from clean, fetched main.
The entrypoint prints the existing proved/tested/unknown evidence matrix plus
native-checker-admitted jewelry/core and demo-erpnext pack LawIR inventories.
`python3 scripts/demo/guarantees_drop.py --result RESULT.json` optionally reuses
the existing full result validator. Pack goals remain unknown without exact
checked goal evidence. Missing data-beat declarations say
**declaration missing → unknown**; scenario names never become law IDs.
Source, declarations and generated goal identities are retained. No authority is granted.
