# Security

Do not post credentials, tenant data, or details of an exploitable vulnerability in
public issues. Use [private vulnerability reporting](https://github.com/Norn-cloud/norn/security/advisories/new).
If reporting is not yet enabled, contact a maintainer privately before sharing sensitive details.

Only the current source release receives fixes. A security report should identify
the affected revision, impact and a minimal synthetic reproduction. Keep real tenant
systems and data out of reproductions. No response-time or disclosure deadline is promised.
