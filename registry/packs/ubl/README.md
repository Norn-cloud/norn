# UBL 2.3 Invoice pack

A standard pack: OASIS UBL 2.3 Invoice mapped onto the REA canon (`canon.Invoice` as a `core.Claim`, supplier and customer as `canon.Party`). No UBL-specific Rust exists; the generic XSD reader in `crates/norn-formats` reads the pinned originals.

- `source.read.json`: the admission (OASIS licence, release 2.3, per-file SHA-256) and what the pack selects and flattens.
- `source.ts`: generated by `norn-format-read`; never edit it.
- `records.ts`: the mapping, with declared gaps (payable amount awaits the EN 16931 scale policy; the originating order is not in the document).
- `ubl.pack.ts`: terms and their correspondences to the UBL types.

The originals are OASIS-copyrighted and recorded in the standards atlas as vocabulary-only, so they are not committed. To regenerate or verify `source.ts`:

```sh
mkdir -p /tmp/ubl && cd /tmp/ubl && curl -fsSLO https://docs.oasis-open.org/ubl/os-UBL-2.3/UBL-2.3.zip && unzip -q UBL-2.3.zip
cargo run -p norn-formats --bin norn-format-read -- registry/packs/ubl/source.read.json --originals /tmp/ubl --check
```

Line-level mapping (`InvoiceLine` as a nested map) and the EN 16931 business rules are the next packs; both are pack work only.
